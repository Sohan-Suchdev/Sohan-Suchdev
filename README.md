## Featured Projects

### zsh-ai-copilot
> **A terminal-native AI agent that converts natural language into validated, environment-aware shell commands. Powered by a persistent local FastAPI daemon, LangGraph, and ChromaDB for context-optimised generation.**

A terminal-native AI assistant that translates natural language queries into executable, distribution-aware shell commands. Unlike stateless web wrappers, this tool operates via a persistent local FastAPI daemon, utilising a LangGraph state machine and a locally embedded ChromaDB knowledge base. By reading your current working directory, shell version, and OS distribution in real time, it provides context-optimised, latency-free command generation tailored precisely to your local environment.

### C++ Path Tracer
> **A lock-free, multi-threaded CPU path tracer built from scratch in C++20. Features a contiguous frame buffer and a complete Monte Carlo integration framework with explicit light importance sampling.**

A high-performance, multi-threaded CPU path tracer built entirely from scratch in C++20. Designed for maximum efficiency, it features a completely lock-free tile rendering architecture backed by a contiguous frame buffer for maximised cache utilisation. The renderer implements a full Monte Carlo integration framework, using explicit light importance sampling and mixture PDFs to dramatically reduce variance and resolve complex lighting paths with minimal visual noise.

### 4D Hyperspace Minesweeper
> **A 4D Minesweeper web game engineered for strict architectural security and performance. Pairs a secure Kotlin/Spring Boot backend with a highly optimised, framework-free Vanilla JS frontend.**

A four-dimensional implementation of Minesweeper built as an architectural showcase. The application pairs a strictly secured Kotlin/Spring Boot backend—utilising robust DTO sanitisation to guarantee zero unrevealed state leakage over the wire—with a highly optimised Vanilla HTML5/JS frontend. By leveraging deterministic O(1) DOM mapping rather than tree traversal, the client seamlessly calculates and renders 80-cell hyperspace neighbourhoods whilst maintaining a flawless 60fps.
