## Featured Projects

*   **zsh-ai-copilot:** A terminal-native AI agent running on a persistent local FastAPI daemon, utilising a LangGraph state machine and ChromaDB for environment-aware, latency-free shell command generation.
*   **C++ Path Tracer:** A lock-free, multi-threaded CPU path tracer built from scratch in C++20, featuring a contiguous frame buffer and a complete Monte Carlo integration framework with explicit light importance sampling.
*   **4D Hyperspace Minesweeper:** A strictly secured Kotlin/Spring Boot backend paired with an optimised, framework-free Vanilla JS frontend to render 80-cell hyperspace neighbourhoods at a flawless 60fps, fully Dockerised with Nginx.
